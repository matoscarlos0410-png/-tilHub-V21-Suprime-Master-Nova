1. ¿QUÉ ES ÚTILHUB?
------------------------------------------------------------

ÚtilHub es un sitio web creado para reunir diferentes
herramientas útiles en un solo lugar.

Su objetivo es ayudar al usuario en tareas cotidianas,
estudio, organización, conversiones, cálculos, texto,
tiempo y otras actividades.


2. NOVA FLOW

4. FUNCIONAMIENTO SIN IA
------------------------------------------------------------

ÚtilHub V21 no necesita inteligencia artificial para
realizar sus herramientas principales.

Las funciones trabajan directamente mediante JavaScript,
HTML y CSS.

Esto permite que muchas herramientas funcionen rápidamente
y que el usuario tenga control directo sobre ellas.


5. DATOS DEL USUARIO
------------------------------------------------------------

ÚtilHub puede guardar determinadas preferencias
localmente en el navegador.

Entre ellas:

- Tema
- Animaciones
- Intensidad de NOVA FLOW
- Modo de rendimiento
- Favoritos
- Herramientas recientes
- Notas
- Tareas
- Listas
- Configuraciones

Los datos locales no necesitan una cuenta para funcionar.


6. FAVORITOS Y RECIENTES
------------------------------------------------------------

Las herramientas pueden aparecer en:

- Favoritos
- Herramientas recientes
- Herramientas rápidas

Esto permite acceder más rápidamente a las funciones
utilizadas con mayor frecuencia.


7. MODO OSCURO Y ANIMACIONES
------------------------------------------------------------

ÚtilHub V21 permite controlar la experiencia visual.

Opciones principales:

- Tema visual
- Activar/desactivar movimiento
- Intensidad de NOVA FLOW
- Rendimiento
- Modo enfoque

También se tiene en cuenta la configuración de reducción
de movimiento del dispositivo.


8. MODO ENFOQUE
------------------------------------------------------------

El modo enfoque reduce elementos innecesarios de la
interfaz para permitir trabajar con una herramienta
con mayor concentración.


9. CÓDIGO QR
------------------------------------------------------------

ÚtilHub puede generar códigos QR a partir de información
introducida por el usuario.

El contenido puede ser un texto o enlace.

La generación del código utiliza un servicio externo
cuando se necesita crear la imagen QR.


10. DICCIONARIO
------------------------------------------------------------

La herramienta de diccionario permite buscar palabras.

Cuando existe conexión, puede consultar información
mediante un servicio externo.

Si no existe conexión, ÚtilHub informa al usuario en lugar
de inventar resultados.


11. COMPRAS
------------------------------------------------------------

Las herramientas relacionadas con compras permiten al
usuario realizar sus propias búsquedas.

ÚtilHub no realiza compras automáticamente.

El usuario decide qué producto comprar y completa el
proceso directamente en el sitio correspondiente.


12. COMIDA
------------------------------------------------------------

La sección de comida sirve para facilitar la búsqueda
de opciones.

ÚtilHub no realiza pedidos automáticamente.

El usuario debe revisar la información y realizar el
pedido directamente con el establecimiento o servicio.


13. PWA — APLICACIÓN INSTALABLE

17. INSTALACIÓN EN GITHUB
------------------------------------------------------------

1. Crear un repositorio en GitHub.

2. Subir los archivos:

   index.html
   style.css
   script.js
   manifest.webmanifest
   sw.js
   README.txt

3. Activar GitHub Pages.

4. Abrir la dirección proporcionada por GitHub.

5. Esperar a que el navegador cargue ÚtilHub.

6. En dispositivos compatibles aparecerá la opción
   para instalar la aplicación.
